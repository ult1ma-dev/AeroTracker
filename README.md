# SkyPro Aeroplanes Coursework

Курсовой проект на Python: консольная программа получает координаты выбранной
страны через Nominatim, запрашивает самолёты в этих пределах у OpenSky Network
и сохраняет результат в JSON. Сохранённые данные можно просматривать,
сортировать по высоте, фильтровать и удалять отдельные записи.

## Установка и запуск

Нужны Python 3.11 или новее и [Poetry 2.2+](https://python-poetry.org/docs/#installation).
CI проверяет Python 3.11 и 3.14. Команды выполняются из корня проекта:

```powershell
poetry config virtualenvs.in-project true --local
poetry env use 3.11
poetry install --with dev
poetry run python main.py
```

В `poetry env use` укажите установленную версию Python или полный путь к
интерпретатору. Окружение создаётся в `.venv`; для PyCharm нужно выбрать
`.venv\Scripts\python.exe`. Точные версии зависимостей зафиксированы в
`poetry.lock`. Пакет проекта не устанавливается: используется
`package-mode = false`.

## Работа с программой

При запуске программа читает сохранённый JSON, если он существует, затем
показывает меню:

| Пункт | Действие |
| --- | --- |
| `1` | Запросить самолёты выбранной страны и сохранить новый снимок |
| `2` | Показать текущий список |
| `3` | Вывести топ N по убыванию высоты |
| `4` | Отфильтровать самолёты по стране регистрации |
| `5` | Отфильтровать самолёты по диапазону высот |
| `6` | Повторно загрузить данные из JSON |
| `7` | Удалить самолёт по шестизначному адресу ICAO24 |
| `8` | **[Дополнительно]** Создать интерактивную карту и HTML-отчёт |
| `0` | Завершить работу |

Пример: выберите `1`, введите `Spain`, затем выберите `3` и введите `5`.
Название страны для географического поиска можно вводить по-русски или
по-английски, если Nominatim распознаёт его.

Для фильтра по стране регистрации используйте полные названия из вывода
OpenSky, обычно на английском: `United States, United Kingdom, Spain`.
Несколько названий разделяются запятыми; пробелы внутри названия сохраняются.
Регистр букв не учитывается. Страна регистрации и страна текущего положения
самолёта — разные поля.

Высота выводится в метрах, скорость — в метрах в секунду. Границы диапазона
высот вводятся отдельно и включаются в результат. Допускаются отрицательные
высоты. Для топа требуется целое положительное N; если записей меньше N,
программа покажет все подходящие. Записи без высоты исключаются из топа и
фильтра по высоте. Отсутствующие значения выводятся как «нет данных» и
сохраняются как JSON `null`; они не подменяются нулём. В выборку входят как
находящиеся в воздухе, так и находящиеся на земле самолёты.

## Дополнительно: карта и HTML-отчёт

Запустите `poetry run python main.py`, выберите **8** и введите название
страны, например `Spain`. Программа запросит свежие данные и создаст один
HTML-файл в каталоге `reports` относительно корня проекта. Он автоматически
откроется в браузере; полный путь также появится в консоли.

В отчёте есть интерактивная карта самолётов, карточки с характеристиками,
статистика, диаграммы, топ-10 по высоте и полная таблица. Поиск по позывному
или ICAO24 и фильтры страны регистрации и состояния изменяют карту и таблицу.
Доступны сортировка таблицы и кнопка печати.

В таблицах отчёта скорость указана в м/с. Карточка средней скорости также
показывает значение в км/ч.

Все ресурсы встроены в HTML: после создания его можно скопировать и открыть
без интернета, установки библиотек и запуска сервера. Автономная подложка
показывает контуры стран Natural Earth, без подробных дорог и городов.
Для получения нового снимка нужен доступ к API. Отчёт показывает время
получения данных и не обновляется автоматически. Самолёты без корректной
пары координат остаются в статистике и таблице, но не отмечаются на карте.

Это дополнение к курсовой: пункты **0–7**, сравнение и валидация самолётов,
абстрактные интерфейсы и формат основного JSON работают по заданию.
Пункт **8** использует отдельный снимок: он не меняет текущую выборку меню
и не перезаписывает `data/aeroplanes.json`. Дополнительные координаты
содержатся только в снимке отчёта. Библиотеки Python сверх зависимостей
основной программы не требуются.

## API и хранение данных

Географические границы — прямоугольный `boundingbox` страны. В него могут
попадать соседние территории; точная проверка государственной границы
не выполняется. Покрытие приёмников OpenSky неполное, поэтому пустой ответ
не доказывает отсутствие самолётов.

Программа использует анонимный запрос актуальных state vectors OpenSky.
OAuth2 и исторические данные в этой версии не реализованы. Доступность
сервиса и лимиты определяет OpenSky; при отказе доступа, ограничении частоты
запросов или сетевой ошибке программа выводит сообщение. Автоматического
периодического опроса нет.

Для публичного Nominatim действует ограничение **не более одного запроса
в секунду**, требуется идентифицирующий `User-Agent` и указание источника.
Приложение выдерживает интервал между запросами и кэширует координаты стран
на время запуска. Перед обращением к сервису ознакомьтесь с
[правилами Nominatim](https://operations.osmfoundation.org/policies/nominatim/).
Для своего развёртывания задайте `NOMINATIM_USER_AGENT` с названием приложения
и контактной информацией. Адрес сервиса можно заменить через настройки.

По умолчанию данные записываются в `data/aeroplanes.json`. Новый запрос
заменяет предыдущий снимок целиком; история запросов не накапливается.
Фильтрация и топ работают с текущим снимком. Запись выполняется через
временный файл с атомарной заменой целевого файла. Повреждённый JSON
не перезаписывается автоматически: программа сообщает об ошибке, а исходный
файл сохраняется для проверки. Ошибка сети или сохранения оставляет текущую
выборку доступной.

Настройки читаются из переменных окружения при запуске:

| Переменная | Значение по умолчанию |
| --- | --- |
| `AEROPLANES_DATA_FILE` | `data/aeroplanes.json` относительно корня проекта |
| `NOMINATIM_URL` | `https://nominatim.openstreetmap.org/search` |
| `OPENSKY_URL` | `https://opensky-network.org/api/states/all` |
| `NOMINATIM_USER_AGENT` | `SkyPro-Aeroplanes-Coursework/0.1.0` |
| `HTTP_TIMEOUT` | `10` секунд, положительное конечное число |

Пример настройки в PowerShell:

```powershell
$env:NOMINATIM_USER_AGENT = "My-Aeroplanes-Coursework/0.1 (contact: you@example.com)"
$env:HTTP_TIMEOUT = "15"
poetry run python main.py
```

`.env` автоматически не читается. Создаваемые JSON-файлы, локальные настройки
Poetry и виртуальное окружение исключены из Git.

## Структура и ООП

```text
main.py                 запуск консольного приложения
src/
    api.py              BaseAPI и адаптер Nominatim/OpenSky на requests
    models.py           Aeroplane, BoundingBox и проверка значений
    storage.py          BaseStorage и JSONSaver
    services.py         получение, сортировка, фильтрация и удаление
    cli.py              меню, ввод и человекочитаемый вывод
    config.py           настройки из переменных окружения
    exceptions.py       ошибки API и хранилища
    snapshots.py        дополнительные снимки с координатами для отчёта
    reporting/          автономная карта, HTML-отчёт и встроенные ресурсы
tests/                  изолированные тесты без реальных HTTP-запросов
data/                   JSON-снимок, создаваемый при работе
reports/                дополнительные HTML-отчёты, исключённые из Git
scripts/check.ps1       общая проверка качества в PowerShell
.github/workflows/ci.yml проверки в GitHub Actions
```

Абстрактные классы на основе `ABC` задают контракты API и хранилища.
Модель самолёта инкапсулирует данные и предоставляет сравнение по высоте и
скорости. Сервис получает API и хранилище через конструктор: их можно заменить
другими реализациями без изменения фильтрации и консоли. Ответственности
модели, HTTP, JSON, операций с выборкой и интерфейса разделены.

## Проверки качества

```powershell
poetry check --lock
poetry run black --check .
poetry run isort --check-only .
poetry run flake8 .
poetry run mypy
poetry run pytest
```

Все проверки одной командой, в том числе из другого рабочего каталога:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\check.ps1
```

Скрипт переходит в корень проекта и останавливается при первой неуспешной
проверке. Black, isort и Flake8 используют длину строки кода 79 символов.
Flake8 также проверяет лимит 72 символа для комментариев и docstring
(правило `W505`). mypy проверяет `src` и `main.py` в строгом режиме.
pytest измеряет покрытие `src` с учётом ветвлений и требует минимум **76%**.
Отчёт выводится в консоль и записывается в `coverage.xml`. Тесты подменяют
HTTP и используют временные файлы, поэтому не требуют доступа к внешним API.

Для автоматических Git-хуков после создания репозитория:

```powershell
poetry run pre-commit install
poetry run pre-commit run --all-files
poetry run pre-commit run --all-files --hook-stage pre-push
```

При коммите isort и Black исправляют форматирование, Flake8 и mypy проверяют
код; при изменении зависимостей проверяется согласованность lock-файла.
Исправленные файлы нужно добавить в коммит повторно. Полный pytest запускается
один раз перед отправкой ветки. Хуки используют инструменты из окружения
Poetry. CI выполняет проверки при push и pull request на Python 3.11 и 3.14.

Схема GitFlow для дальнейшей работы: стабильная версия в `main`, разработка
в `develop`, отдельные изменения в `feature/*`; подготовка выпуска и срочные
исправления — в `release/*` и `hotfix/*`. Конфигурация CI начнёт выполняться
после размещения репозитория на GitHub.
